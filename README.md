# Contentpilot- WP Content Management & SEO 

=== ContentPilot – Content Ideas, Competitor Analysis & SEO ===
Contributors: yourname
Tags: seo, content ideas, competitor analysis, open graph, alt text
Requires at least: 5.8
Tested up to: 6.8
Requires PHP: 7.4
License: ContentPilot Personal Use License
License URI: LICENSE.txt

Analyze your content, get content ideas, compare with competitors, preview social shares, fix image alt text and improve SEO. Completely free.

== Features ==
* Content analysis & scoring for every post/page
* Free built-in content idea generator (+ optional AI with your own key)
* Competitor comparison via public RSS/sitemap, content gap keywords, improvement tips
* SEO title, meta description, focus keyword, noindex, SERP preview
* Social share previews (Facebook, X, LinkedIn, WhatsApp) with custom image
* Open Graph, Twitter Card and Article schema output
* Bulk image alt text editor + auto alt on upload
* Tag suggestions
* Donation page

== Installation ==
Upload the contentpilot folder to /wp-content/plugins/ and activate. Open ContentPilot in the admin menu.
